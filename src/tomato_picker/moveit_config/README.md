# 手眼伺服碰撞模型

手眼伺服使用 `handeye_tip` 规划组和 `tip` 工具坐标，六轴关节反馈更新机械臂姿态；未反馈的 `joint7`、`joint7-1`、`joint7-2` 保持模型默认值 0

`Link6` 的网格包含末端壳体和导向结构，`Link7` 是中央齿轮，`Link7-1`、`Link7-2` 的网格各包含齿条和夹指
SRDF 仅允许以下五对末端内部接触

| 碰撞对 | 允许原因 |
| --- | --- |
| `Link6` / `Link7` | 齿轮安装在壳体上，是直接父子部件 |
| `Link6` / `Link7-1` | 夹指及齿条在壳体的导向结构中滑动，是直接父子部件 |
| `Link6` / `Link7-2` | 同上，对侧夹指及齿条 |
| `Link7` / `Link7-1` | 齿轮与齿条啮合，是传动接触 |
| `Link7` / `Link7-2` | 同上，对侧齿条 |

夹指彼此、末端与其他机械臂部件、所有机器人部件与外部障碍仍进行碰撞检查
URDF 的碰撞网格、尺寸和安装变换没有缩小或移除；LINE 的碰撞检查和完整路径比例要求保持启用

全零六轴姿态仍存在 `Link2` / `base_link` 等真实模型碰撞，不能用作合法规划起点；启动伺服前应使用实际测量的、处于关节范围内且无碰撞的姿态
